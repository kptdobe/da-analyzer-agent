# DA Analyzer Agent

Claude Code workspace for DA (Document Authoring) log analysis, error investigation, and code review across DA repos.

## What you can do

- **Log querying** — Cloudflare access + worker trace logs via ClickHouse
- **Error investigation** — 500s, exceptions, worker failures, root cause in source
- **User behavior analysis** — traffic patterns, session analysis, unique users
- **Cross-repo code analysis** — da-live, da-admin, da-collab, da-content, da-nx
- **PR creation** — investigate → locate code → write fix → open PR

## Setup

### Prerequisites

- Node.js 18+
- [Claude Code](https://claude.ai/code) CLI (`npm i -g @anthropic-ai/claude-code`) if using Claude Code
- VS Code with GitHub Copilot if using the global VS Code MCP configuration
- [GitHub CLI](https://cli.github.com) (`brew install gh && gh auth login`)
- ClickHouse API key + secret for the DA logs service

### Install

```bash
git clone https://github.com/kptdobe/da-analyzer-agent
cd da-analyzer-agent
chmod +x setup.sh && ./setup.sh
```

`setup.sh` will:

1. Install ClickHouse MCP server dependencies
2. Add API credentials to your shell profile (`~/.zshrc`) for Claude Code
3. Create `repos/` symlinks pointing at your local DA repo clones
4. Generate `.claude/settings.local.json` with the local MCP server path

### VS Code and GitHub Copilot

The ClickHouse MCP is configured globally in VS Code at:

```text
~/Library/Application Support/Code/User/mcp.json
```

The global entry runs `scripts/clickhouse-mcp-keychain.sh`, which reads the
credentials from the macOS login Keychain. This keeps them out of the repository,
`mcp.json`, and shell history. Store them once with these commands; each command
prompts for the value without displaying it:

```bash
security add-generic-password -U -a "$USER" -s copilot-clickhouse-api-key -w
security add-generic-password -U -a "$USER" -s copilot-clickhouse-api-secret -w
```

After changing credentials, update the corresponding Keychain item by running
the same command again. The `-U` option replaces the existing value. Reload VS
Code with **Developer: Reload Window** so the next Copilot session starts a new
MCP process.

The global configuration uses an absolute path to this checkout. If the project
moves, update the `args` path in the user-level `mcp.json`.

### Start

For Claude Code:

```bash
cd da-analyzer-agent
source ~/.zshrc   # if this is a new terminal after setup
claude
```

For VS Code, open any workspace and start a Copilot session. The global
ClickHouse MCP is available without adding a workspace `.vscode/mcp.json` file.

## Repo layout

```
da-analyzer-agent/
  CLAUDE.md                         — DA knowledge base for Claude
  setup.sh                          — one-time per-developer setup
  mcp-servers/
    clickhouse/                     — ClickHouse MCP server
      src/index.js
      package.json
  .claude/
    settings.json                   — permissions (checked in)
    settings.local.json             — MCP server path (generated by setup.sh, gitignored)
  scripts/
    clickhouse-mcp-keychain.sh      — global VS Code launcher using macOS Keychain
  repos/                            — symlinks to local DA repo clones (gitignored)
    da-live → ~/…/da-live
    da-admin → ~/…/da-admin
    …
```
